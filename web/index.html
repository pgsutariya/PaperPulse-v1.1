Replay this trade against past sessions

Monte Carlo resamples each bar slot from the session pool; the history replay runs the opening-range rule over every session as it actually happened. When one simulated bar spans both the stop and the target the stop is taken — without tick data the order is unknowable, and assuming the win would inflate every win rate.

Lot book

Indian listed equity: a holding turns long-term only after more than 12 months, so a sale on the anniversary itself is still short-term. There is no wash-sale rule to model. FIFO is what the depositories actually apply — highest-cost and specific-lot are planning views for “what would this sale cost me?”, not filing methods.
